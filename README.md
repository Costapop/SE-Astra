# SE-Astra v1.3.0

Веб-приложение для анализа дефектов тонких плёнок по спектрам эллипсометрии Ψ(λ), Δ(λ). Адаптивный интерфейс, светлая и тёмная темы, все вычисления на устройстве пользователя.

Основано на [SE-AI v2.0.0](https://github.com/Costapop/SE-AI/tree/v2.0.0), коммит `a32a9b49204909dcb97c18847c0a562beb93ac43`. Происхождение модели сохранено; исправления вычислений и представления результатов описаны в истории выпуска. С v1.2.0 анализ выполняется в Web Worker с отображением прогресса.

Эта ветка содержит релиз **SE-Astra v1.3.0**. Исправления по результатам научной и редакционной проверки: [Release_Notes.md](Release_Notes.md).

## Запуск

**Онлайн:** [размещённая версия SE-Astra](https://se-astra.costapop.chatgpt.site/). Её версия может отличаться от этого релиза; номер указан в интерфейсе. Доступ определяется настройками опубликованного приложения.

**Без установки:** скачайте репозиторий как ZIP, распакуйте и откройте `index.html`. Папка `vendor` должна оставаться рядом. Графики, импорт Excel и формулы работают без CDN и без подключения к интернету. Данные измерений не отправляются на сервер.

**Через локальный сервер** (Node.js 20+):

```sh
npm start
```

Откройте `http://127.0.0.1:4173`. Установка зависимостей для запуска не требуется. Порт можно задать переменной `PORT`.

**GitHub Pages:** Settings → Pages → Deploy from a branch → ветка со сборкой / `(root)`. Файл `.nojekyll` включён. Приложение использует относительные пути и работает в подпапке репозитория. Наличие исходного кода в GitHub само по себе не включает Pages.

## Первый анализ

1. На вкладке **Образец** уже выбран TiO₂ на BK7, 65°. Можно выбрать другой из девяти образцов или перетащить собственный файл.
2. Проверьте материал, подложку, угол, номинальную толщину, шум и полосу прибора в **Априорных условиях**. На телефоне они раскрываются по нажатию «Условия измерения и материал».
3. Нажмите **Выполнить все шаги**. Приложение выполнит опорный фит, обучит классификатор, определит вероятности моделей и выполнит окончательный физический фит. Время зависит от устройства, спектра и задней стороны подложки; стандарт — 800 обучающих примеров.
4. Изучите параметры, формальные ошибки, систематику, остатки и дисперсию. Для встроенных и симулированных спектров появится сравнение со скрытой истиной.

Анализ идёт непрерывной лентой: спектр и завершённые шаги остаются на странице, а новый шаг плавно прокручивает её вниз. Закреплённая сверху легенда всегда показывает все этапы и выделяет текущий; после расчёта выделение следует за ручной прокруткой. По легенде можно вернуться к готовому результату. Между автоматическими шагами готовый результат остаётся на экране не менее 2,4 с; остановка работает и во время этой паузы. На шаге 2 отдельные индикаторы показывают подготовку спектров, обработку якорных признаков и обучение. На шаге 3 в анимации остаются только пять наиболее вероятных комбинаций дефектов и их вероятности: график остатка и названия якорных каналов убраны. Кадры меняются не чаще одного раза в 0,6 с; полосы вероятности изменяются плавно. Это визуализация одного прохода softmax: промежуточные оценки используют часть признаков, окончательные вероятности — полный вектор модели. Итог совпадает с выходом обученной модели.

Шаг 4 показывает реальные итерации, χ²/ν, текущую толщину и кривую сходимости с логарифмической шкалой в компактной панели. Анимации шагов 3 и 4 автоматически располагаются в видимой области; высота графика учитывает высоту экрана. Подробные пояснения раскрываются отдельно под панелью. Статус остаётся активным и при вычислении погрешностей, повторе после вето и проверке скрытой истины. Таблицы результатов анализа адаптируются к ширине раздела; широкие таблицы иллюстраций допускают горизонтальную прокрутку. Поддерживается настройка уменьшения движения.

Все тяжёлые вычисления анализа выполняются в фоновом Web Worker, встроенном в HTML: интерфейс остаётся доступным, отображает прошедшее время и позволяет **Остановить** расчёт. После остановки можно повторить шаг; после сбоя элементы управления разблокируются. Нужен современный браузер с поддержкой Web Worker и Blob URL; при запрете фоновых вычислений показывается сообщение.

Каждый этап можно запускать отдельно. После изменения условий предыдущие результаты помечаются устаревшими: начните с опорного фита, чтобы переобучить модель для новых условий. Во время анализа изменение входных данных заблокировано.

## Условия иллюстраций

Размеры дефектов автоматически заполняются из действующего окончательного фита: модуль градиента в процентах, толщина EMA-слоя в нм и `k₄₀₀` хвоста в единицах ×10⁻³. Исключённый окончательным фитом дефект получает размер 0. Пока окончательного фита нет или он устарел, используются поля **Симулятора измерения**. Источник подписан под размерами. Выбор «Параметры плёнки» отдельно задаёт базовую толщину и дисперсию.

Размеры можно изменить вручную и нажать **Построить все иллюстрации**. Ноль остаётся нулём и в расчётах. Ручные значения сохраняются при переходах между разделами в текущем сеансе; перезагрузка приложения сбрасывает их. Новый фит или изменение исходных размеров симулятора обновляет источник. Кнопка под полями возвращает значения текущего источника. Если условия меняются во время расчёта, текущие графики используют единый снимок размеров и помечаются устаревшими.

Легенды всех 41 графика оформлены едиными переключателями. Сплошная или пунктирная линия, точки и столбцы повторяют обозначения графика. Нажатие скрывает или показывает ряд; выбор сохраняется при перерисовке, смене темы, единиц, полного экрана и режима показа. Для двенадцати отпечатков по длине волны и каждой сетки эффектов прибора одна легенда Ψ/Δ управляет всеми панелями. В плоскости отпечатков используется непрерывная цветовая шкала λ.

Общая легенда **Якорных паттернов** скрывает или показывает выбранный ряд на всех четырёх панелях. В HW отклонения Ψ и Δ считаются относительно подложки; в QW Ψ сравнивается с однородной плёнкой, а Δ — с подложкой после вычета 180°. PNG каждой панели содержит собственную легенду.

| Результаты | Формальная ошибка и систематика, физическое вето незначимых дефектов, χ²/ν, остатки, n/k, сравнение с истиной и причины отклонений |

## Формат измерений

```csv
lambda,psi,delta,sigPsi,sigDelta
400,12.52,302.41,0.02,0.04
402,12.87,315.66,0.02,0.04
```

Нужно минимум 20 строк данных. λ — в нанометрах, Ψ/Δ и σ — в градусах. σ необязательны: при их отсутствии используются значения из условий. CSV допускает запятые, `;` или табуляцию; при `;` и табуляции допустима десятичная запятая. XLSX/XLS читается с первого листа. Длины волн сортируются, Δ приводится к 0–360°. Дубликаты λ, неположительные λ/σ и Ψ вне 0–90° отклоняются с понятной ошибкой.

## Научные границы

Модель рассчитана на один угол измерения и заданный набор дефектов: линейный градиент показателя, эффективный слой шероховатости и причинный хвост поглощения. Она не моделирует произвольные многослойные структуры, анизотропию, клиновидность или частичную когерентность. `k₄₀₀` означает добавку хвоста при 400 нм, а не полный коэффициент поглощения материала.

Вероятность класса — выход классификатора для заданного набора моделей и условий обучения, а не подтверждённая вероятность наличия дефекта в реальном образце. Формальная погрешность и систематика выводятся отдельно. Высокий χ² после окончательного фита может означать, что набор моделей недостаточен. У материалов с краем поглощения внутри диапазона ограничения фиксированной дисперсии особенно заметны.

Подробные формулы, настройки и методические ограничения: [научная модель SE-Astra v1.3.0](docs/SCIENTIFIC_MODEL.md). Проверки физики: [VERIFICATION.md](docs/VERIFICATION.md).

## Разработка и проверки

```sh
npm ci
npm run build
npm run verify:book
npm run verify:backside
npm run examples:check
npm run test:examples-files
npm run test:audit
npm run test:analysis
npm run test:astra
npm run test:illustrations
npm test
npm run test:demo
npm run test:ui
```

`test:examples-files` сверяет все числовые ячейки девяти XLSX-спектров и параметры ключа ответов с JSON и ядром. `test:audit` проверяет численные и статистические исправления v1.3.0. `test:astra` проверяет новые элементы интерфейса, импорт, валидацию, опорный фит, устаревание и WebMCP. `test:illustrations` проверяет приоритет и смену источника размеров, единицы окончательного фита, нулевые дефекты в расчётах, общий снимок построения, связанную легенду, преобразование в σ и экспорт. `test:demo` прогоняет все разделы иллюстраций по девяти образцам. Полный `test:ui` может быть существенно медленнее браузера.

```text
src/ellip_core.js    физическое ядро на основе SE-AI v2.0.0
src/app_template.html разметка и вычислительные сценарии
src/astra.css        оформление и адаптивная компоновка
src/astra.js         навигация, сводка, состояние условий, WebMCP
examples/            девять спектров и ключ ответов
vendor/              фиксированные локальные библиотеки и лицензии
index.html           готовое приложение
dist/               готовая статическая сборка для хостинга
tools/build.js      воспроизводимая сборка index.html и dist/
tools/serve.js      локальный сервер без зависимостей
test/               численные и интерфейсные проверки
```

После изменения `src/` выполняйте `npm run build` и коммитьте обновлённые `index.html` и `dist/`. Сервер не делает сборку автоматически.
