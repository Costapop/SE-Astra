# SE-AI v2.0.0 — страница «Иллюстрации»: проверка на всех образцах, точные якоря, синхронизация с «Анализом»

**▶ Запустить приложение:** https://costapop.github.io/SE-AI/releases/v2.0.0/ · страница «Иллюстрации»: https://costapop.github.io/SE-AI/releases/v2.0.0/#demo

Версия развивает функциональность **v1.3.3** (ветки v1.3.4–v1.3.8 и v1.4.0 в неё не входят) и закрывает найденное при проверке страницы «Иллюстрации» на всех девяти встроенных образцах.

**Что исправлено**

- Якорные паттерны и сводка — точные значения модели в λ якорей (положения якорей уточняются на точной модели). Раньше интерполяция с сетки давала у однородной плёнки до 0.15° (≈7 σ) вместо нуля.
- У материалов с собственным поглощением (SiNₓ:H, WO₃, CeO₂) однородная плёнка не «исчезает» в синих HW-якорях полностью — подписи исправлены, в сводке появляется примечание с величиной эффекта.
- Кнопка «Таблица»: у всех графиков — сортировка и форматирование чисел; у отпечатков — строки по длине волны, столбцы Ψ и Δ на каждый ряд (раньше — тысяча строк по одному значению).
- Смена «Априорных условий», параметров прибора и фиты на странице «Анализ» помечают иллюстрации устаревшими; при изменённых условиях иллюстрации считают свой опорный фит, не трогая результаты «Анализа». Подложка, доля и толщина в разделе «Задняя сторона» и параметры в разделе «Прибор» подставляются со страницы «Анализ» с закреплением изменённых полей и кнопкой «Как на «Анализе»».
- Для поглощающей подложки (c-Si) раздел «Задняя сторона» сообщает, что эффекта нет; размеры дефектов в легенде якорных паттернов; источник E_g, E₀ на графике ε₂; правки формулировок.

**Проверки.** `npm run test:demo` — страница «Иллюстрации» по всем встроенным образцам (тексты, 48 графиков, таблицы, якоря, синхронизация); `npm run test:ui`, `npm run verify:book`, `npm run verify:backside`, `npm run examples:check` — без изменений в ядре, все пройдены.
