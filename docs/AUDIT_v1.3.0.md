# Аудит SE-Astra 1.2.3 и исправления 1.3.0

Дата проверки: 8 октября 2026 года. Проверена версия `v1.2.3`, коммит `63a2dbd66eb179797c8b174ab16ea1c6b9127ab4`. Исправления собраны в версии `1.3.0`.

Проверка охватывает физические формулы, численные методы, статистические оценки, графики, легенды, таблицы, примеры, комментарии и описания. Профессиональный стиль и форматирование рассмотрены отдельно в разделе 4. Это проверка программной реализации и согласованности модели; экспериментальная аттестация на реальных образцах не проводилась.

## 1. Проверяемый исходный релиз

Скачан [официальный архив 1.2.3](https://github.com/Costapop/SE-Astra/releases/tag/v1.2.3). Его SHA-256 — `319eead89132b6f591b8ba8a8958169480938a25ceeecdecb959afe24604045c`, совпадает с опубликованным GitHub. Все 178 файлов архива побайтно совпали с файлами тега.

До изменений успешно выполнены прежние проверки физической модели, задней стороны подложки и воспроизводимости примеров. Это не исключило ошибок: перечисленные ниже случаи не покрывались прежним набором тестов.

## 2. Физика, формулы и вычисления

| Ошибка в 1.2.3 | Влияние и исправление в 1.3.0 |
|---|---|
| Интерполяция таблиц Si экстраполировала внутренний кубический участок на крайние интервалы | Для Green при 250 нм получалось n = 1.665, а сразу справа — около 1.304. Два крайних интервала теперь линейно соединяют действительные узлы; внутри сохранена кубическая интерполяция. |
| Комплексный квадратный корень терял малую мнимую часть | При малом хвосте TiO₂ вычислялось k = 0 при ненулевом ε₂. Малая компонента восстанавливается через тождество 2nk = ε₂. Исправлены все соответствующие пути расчёта. |
| В пределе полного отражения могла выбираться растущая волна | В конвенции N = n − ik выбирается пассивная ветвь Im(N cos θ) ≤ 0. Проверены затухание и R = 1. |
| Неопределённость k₄₀₀ переносилась только через A_k | Добавлены зависимости от A, A_uv, E_g и полная ковариация. В контрольном примере SiNₓ оценка σ выросла с 1.37164·10⁻⁵ до 1.69306·10⁻⁵, то есть на 23.4 %. |
| Систематика k₄₀₀ теряла знаки совместного изменения параметров | Для каждого источника сохраняется вектор сдвига параметров; производная величина рассчитывается по всему вектору. Проверено повторными фитами при изменённом угле. |
| Пропускались QW-точки до первой HW-точки | HW и QW ищутся независимо на каждом сегменте развёрнутой фазы; локальные развороты больше не обрабатываются как монотонная обратная интерполяция. |
| Недостаток якорей обнулял даже глобальные RMS остатков | RMS Ψ и Δ сохраняются; обнуляются только недоступные якорные признаки. |
| Неизвестная погрешность превращалась в нулевой порог вето | Недоступная ковариация больше не означает нулевую ошибку. Значимость помечается неопределённой; автоматическое удаление по недостоверному порогу не применяется. |
| Нулевая толщина непрерывного профиля и нулевая сила осциллятора давали 0/0 | Добавлены корректные предельные вычисления отражения и производной. |
| Оценка точности приближения спектральной полосы была завышена | Исправлено различие ошибки относительно сигнала и относительно поправки. При периоде 20 нм и σ = 0.7 нм отброшенный член составляет около 1.21 % от поправки второго порядка, а ошибка центральной разности с шагом 1 нм — около 0.82 %. |

Сохранены и проверены: конвенция ρ = r_p/r_s, формулы Френеля, рекурсия Эйри, матричный метод Абелеса, баланс энергии, непрерывный профиль Риккати, среда Бруггемана, производные модели, преобразование Крамерса–Кронига, некогерентная задняя сторона и усреднение ненормированных элементов Мюллера по полосе.

Отдельное независимое сравнение 2000 случайных пассивных стопок двумя методами отражения дало максимальное |Δr| = 1.91·10⁻¹⁴. Оно включало 0–3 слоя, n от 0.25 до 5, нулевое и малое поглощение, затухающие ветви.

## 3. Статистика, графики, легенды и экспорт

| Ошибка в 1.2.3 | Исправление |
|---|---|
| RMSE регрессий оценивался на спектрах, уже использованных для их обучения | Контрольные регрессии обучаются и стандартизуют признаки только на обучающей части. Отложенные спектры используются только для оценки. Итоговые регрессии затем обучаются на всех данных. |
| Кривая окончательного фита заново выбирала число подслоёв по найденному градиенту | Используется фактическое `fin.M`, на котором получены остатки и χ². |
| Бюджет отклонений пропускал изолированный дрейф Δ и различие толщины подложки | Учитываются оба канала дрейфа и оба параметра задней стороны: доля f и толщина d_s. |
| Плоскости остатков ошибочно считались отсортированными по X | Исправлены настройки настоящего Chart.js; оси и поиск ближайшей точки корректны для произвольного порядка остатков. |
| Таблица плоскости остатков объединяла разные длины волн при одинаковом Ψ-остатке | Точки несут λ; таблицы и подсказки сохраняют связь с исходной длиной волны. |
| Разрыв Δ через 0/360° удалял реальный отсчёт | Между отсчётами вставляется разрыв линии; все исходные значения сохраняются. |
| Экспорт мини-графиков терял заголовки осей, название эффекта и его параметры | PNG включает название фигуры и панели, параметры эффекта, оси и легенду. Длинные заголовки переносятся; экранные настройки восстанавливаются после экспорта. |
| Таблицы не различали n, k и единицы некоторых панелей | Заголовки содержат величину и единицу; малые ненулевые числа отображаются научной записью. Убрано слияние близких X из-за предварительного округления. |
| Пояснение мини-графиков не соответствовало выбранному виду | Тексты меняются вместе с переключением между плоскостью остатков и графиками по λ. |
| Ненулевой k и малая деполяризация объявлялись отсутствующими | Подписи отражают вычисленные значения и ограниченную чувствительность, без вывода об отсутствии эффекта. |

RMSE не является неопределённостью результата измерения. Вероятности softmax — оценки внутри заданного набора классов и синтетической обучающей модели; их калибровка на реальных измерениях не доказана. Бюджет отклонений зависит от порядка исключения факторов и не является единственным разложением ошибки.

## 4. Отдельная проверка профессионального стиля и форматирования

Исправлены содержательные неточности и неоднозначные формулировки:

- Согласованы N = n − ik, ε = ε₁ − iε₂ и положительная величина потерь ε₂ = −Im ε. Уточнён постоянный член ε∞ = 1.
- k назван коэффициентом экстинкции; отделены полный k плёнки и добавка хвоста k₄₀₀. Уточнены единицы сил осцилляторов и УФ-полюса.
- Уточнено, что производная по E_g и якобиан при учёте задней стороны используют конечные разности; снято общее обещание отсутствия ошибки усечения.
- Устранено универсальное утверждение о знаке градиента по одному якорному отклонению: знак зависит от геометрии и конвенции остатка.
- HW/QW названы фазовыми диагностическими якорями: совпадение фаз не гарантирует физического полуволнового условия или равенства Ψ плёнки и подложки. Убраны обещания независимости каналов от дисперсии и однозначного определения дефекта.
- Опорная модель описана как однородная модель с собственной дисперсией материала; она не объявляется прозрачной для всех материалов.
- Подавление задней стороны кремнием ограничено соответствующим диапазоном: для c-Si 0.5 мм при 65° множитель затухания w около 8.1·10⁻³⁹ при 800 нм, но около 0.70 при 1100 нм. Прежнее безусловное утверждение об исчезновении задней стороны исправлено.
- Независимый шум с меняющейся по λ дисперсией больше не называется «цветным».
- Убраны необоснованные обещания точности, неизбежного роста качества с размером выборки, отсутствия ложных дефектов и полного устранения всех ошибок.
- Формальные ошибки, систематика условий и модельное смещение явно разделены. Неопределённая погрешность не показывается как ноль.
- Девять примеров названы синтетическими учебными данными; им не приписывается происхождение из реальных измерений.
- Версии интерфейса, руководства, научной модели и пакета согласованы с 1.3.0; прежние записи истории выпусков сохранены.

Во всех десяти XLSX-файлах проверены заголовки и единицы. Исправлены переносы, высоты строк, закрепление областей, форматы чисел и настройки печати листов условий. В ключ ответов добавлен E_uv с единицей эВ; уточнены единицы A, A_uv, A_k и длины волн для n/k. Тексты назначения и примечания обозначают синтетический характер данных. Числа спектров после округления не изменились относительно 1.2.3; все 9 120 числовых ячеек сверены с JSON.

Визуально проверены рендеры всех девяти листов «Условия» и трёх диапазонов ключа ответов. Использовались Artifact Tool для отрисовки и поставляемый SheetJS для чтения; само приложение Microsoft Excel не запускалось.

## 6. Сохраняющиеся ограничения

Правильная классификация не гарантирует метрологическую точность параметров. В примере CeO₂ получено k₄₀₀ ≈ 1.61·10⁻³ при заданном 1.20·10⁻³, формальной и систематической оценках около 0.04·10⁻³ каждая. При χ²/ν ≈ 5.35 это показывает модельное смещение: фиксированные E₀ и C отличаются от истинных; E_uv в этом примере совпадает. Неопределённость самой формы дисперсии не входит в выводимую систематику условий. Это ограничение теперь прямо описано в интерфейсе и справочнике.

Другие пределы модели:

- Одноугловая обратная задача может иметь коррелированные параметры и локальные минимумы. Локальная ковариация не обеспечивает точного покрытия доверительного интервала у границ или при несоответствии модели.
- Задняя сторона учитывается как некогерентная сумма; определения эффективных Ψ/Δ при деполяризации должны совпадать с определениями конкретного прибора.
- Полоса в окончательном фите остаётся приближением второго порядка. Для узких интерференционных особенностей необходима отдельная проверка полной свёрткой.
- HW/QW определяются по эллипсометрической фазе; при изменении фазы более чем на 180° между соседними отсчётами развёртка неоднозначна.
- Таблицы подложек вне диапазона фиксируются на крайних значениях. Это не физически обоснованная экстраполяция.
- Предел k₄₀₀ = 0.05 применяется к генерации и задаёт предел A_k по справочной дисперсии; найденный k₄₀₀ при изменённой дисперсии не ограничен им строго.
- Крайне толстые сильно поглощающие слои могут переполнять матричные вычисления. Универсальная устойчивая модель таких режимов в этот релиз не вводилась.

## 7. Научные источники и воспроизводимость

Закон распространения неопределённости с корреляциями сверялся с [NIST TN 1297, приложение A, формула A-3](https://www.nist.gov/pml/nist-technical-note-1297/nist-tn-1297-appendix-law-propagation-uncertainty). Матричная оптика и выбор пассивной ветви сверялись с [S. J. Byrnes, Multilayer optical calculations](https://arxiv.org/html/1603.02720v5), с явным приведением временной конвенции к N = n − ik. Коэффициенты BK7 проверены по [данным SCHOTT](https://media.schott.com/api/public/content/41e799d0bf874807a0bb8e702fbb75b5?v=54856406); формула кварца — по первичной статье Malitson, JOSA 55, 1205–1209 (1965). Проверка Tauc–Lorentz включает независимое численное интегрирование Крамерса–Кронига; повторная построчная сверка недоступного полного текста Jellison–Modine не заявляется.

Новые проверки находятся в `test/physics_audit.js`, `test/plot_audit.js` и `test/example_files.js`; общий запуск — `npm run test:audit`. Подробные исходные научные проверки описаны в [VERIFICATION.md](VERIFICATION.md), модель — в [SCIENTIFIC_MODEL.md](SCIENTIFIC_MODEL.md), состав выпуска — в [Release_Notes.md](../Release_Notes.md).
