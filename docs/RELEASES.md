# Выпуски SE Astra

## 1.1.0 — 29 сентября 2026

- Размеры дефектов на странице «Иллюстрации» берутся из действующего окончательного фита; без него — из симулятора. Градиент переносится по модулю, k₄₀₀ — с переводом в ×10⁻³. Убраны независимые начальные значения 1 / 2 / 1.
- Нулевые размеры сохраняются в полях, легендах и физическом расчёте. Пустые и недопустимые значения отклоняются с объяснением.
- Добавлены подпись источника и возврат к его значениям. Ручные изменения сохраняются до смены источника. Построение использует единый снимок размеров; изменение условий во время расчёта не смешивает параметры разных графиков.
- Общая доступная с клавиатуры легенда управляет всеми четырьмя якорными паттернами. Видимость сохраняется при смене единиц, темы и полноэкранного режима.
- Уточнены опорные величины HW/QW, заголовки разделены на две строки. Сетка адаптируется к доступной ширине. В полноэкранном режиме устранён рост высоты canvas; при экспорте PNG каждая панель получает собственную легенду.
- Для больших градиентов иллюстрации используют 40/80/160 подслоёв, как окончательный фит. Физическое ядро SE-AI не изменено.
- Проверено: `test:astra`, `test:illustrations`, полный `test:demo` по девяти образцам и синхронизация условий. Выполнена проверка в реальном браузере, включая окончательный фит и переключение режимов.
