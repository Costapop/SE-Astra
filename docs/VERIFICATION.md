# Проверка физики и математики приложения по книге Фурмана и Тихонравова

Источник: Sh. A. Furman, A. V. Tikhonravov, *Basics of Optics of Multilayer Systems*, Editions Frontières, 1992 (глава 1 — теория спектральных характеристик слоистых сред). Проверка выполнена скриптом `test/verify_book.js` (`npm run verify:book`): формулы книги реализованы независимо от ядра приложения, результаты сравниваются численно. Раздел 7 — итоги двух независимых проверок v1.2.0 и исправления v1.2.1.

## 1. Конвенции (разделы 1.1.1–1.1.3)

| положение книги | в приложении | результат |
|---|---|---|
| Временной множитель $e^{+i\omega t}$; тогда комплексный показатель имеет отрицательную мнимую часть, $\tilde n = n - ik$ (сноска 1 к разд. 1.1.1) | `N = [n, −k]` всюду: плёнка (`filmN`), подложки (`substrateN`), EMA-слой | совпадает |
| Дисперсия Тауца–Лоренца записана в литературе для $e^{-i\omega t}$ ($\varepsilon_2 \ge 0$); переход к конвенции книги — комплексное сопряжение (то же примечание книги) | `filmN`: $N = \sqrt{\varepsilon_1 + i\varepsilon_2}$, затем мнимая часть берётся с минусом | совпадает |
| Закон Снеллиуса $\alpha = n_a \sin\gamma_a$ одинаков во всех слоях; в поглощающей среде угол комплексный (1.1.10–1.1.11) | `cosT(N, s0²) = sqrt(1 − s0²/N²)`, главная ветвь | совпадает |
| Прошедшая волна в поглощающей подложке затухает: при $e^{+i\omega t}$ нужно $\mathrm{Im}(q_s) \le 0$ | для c-Si при 400 нм, 65°: $\mathrm{Im}(N\cos\gamma) = -0.392 < 0$ | выполнено |
| Френель для $s$: $r_s = (q_a - q_s)/(q_a + q_s)$, $q = n\cos\gamma$ | `fresnelPS`: $r_s = (N_i c_i - N_j c_j)/(N_i c_i + N_j c_j)$ | тождественно |
| Френель для $p$ через тангенциальные компоненты **E**: $r_p = (q_a - q_s)/(q_a + q_s)$, $q = n/\cos\gamma$; книга отмечает, что «очень часто» $r_p$ записывают с противоположным знаком (определение через **H**) | `fresnelPS`: $r_p = (N_j c_i - N_i c_j)/(N_j c_i + N_i c_j)$ — эллипсометрическое определение (Аззам–Башара, Фудзивара) | $r_p^{\text{прил}} = -\,r_p^{\text{книги}}$, проверено до $4\cdot10^{-15}$ |

Следствие последней строки: $\Delta^{\text{прил}} = \Delta^{\text{книги}} + 180°$. Выбор приложения соответствует эллипсометрическим приборам: для прозрачной подложки $\Delta = 180°$ ниже угла Брюстера и $0°$ выше, при нормальном падении $\rho = -1$ (проверено). Это не ошибка, а соглашение; в README оно оговорено.

## 2. Рекурсия Эйри против матричного метода Абелеса (разделы 1.2.1, 1.2.3)

Ядро вычисляет $r_p$, $r_s$ рекуррентной формулой (1.2.18) книги: $r_{j+1,0} = (r_{j+1,j} + r_{j,0}e^{-2i\varphi_j})/(1 + r_{j+1,j} r_{j,0} e^{-2i\varphi_j})$, $\varphi_j = k n_j d_j \cos\gamma_j$, от подложки к внешней среде. В тесте независимо реализован матричный метод: характеристические матрицы (1.2.9), произведение от внешней среды к подложке (1.2.11), формулы (1.2.13)–(1.2.14) для $t$ и $r$, $T = \mathrm{Re}(q_s)/\mathrm{Re}(q_a)\,|t|^2$ (1.1.23).

Стек из 42 слоёв (TiO₂ 1000 нм с градиентом +5 % как 40 подслоёв, EMA-слой 2 нм, подложка c-Si с поглощением), 65°, 400–800 нм: $\max|\Delta r_s| = 4\cdot10^{-15}$, $\max|r_p^{\text{прил}} + r_p^{\text{книги}}| = 4\cdot10^{-15}$, $\Psi$ и $\Delta$ совпадают до $10^{-12}$°.

## 3. Численный пример книги: таблица 1.2

Семнадцатислойный узкополосный фильтр $S\,(HL)^4\,xH\,(LH)^4$, $n_s = 1.52$, $n_H = 2.3 - 0.0002i$, $n_L = 1.35 - 0.0002i$, $\lambda_0 = 500$ нм, нормальное падение; книга приводит $T$, $R$, $A$ в 11 точках. Матричный метод из теста воспроизводит все 33 числа с точностью **0.001 %** при двух уточнениях, которые пришлось подобрать, потому что текст книги извлечён из PDF с искажениями: центральный слой имеет оптическую толщину $\lambda_0$ (четыре четвертьволновые), а столбец $R$ соответствует свету, падающему со стороны подложки ($T$ от направления не зависит и воспроизводится в обе стороны; $R$ при поглощении зависит — раздел 1.3.2). Рекурсия ядра для того же стека совпадает с матричным методом по $R$ прямого хода до $5\cdot10^{-12}$ %.

Этим одновременно проверены формулы Френеля, фазовая толщина $2\pi n d/\lambda$, знак мнимой части показателя (при неверном знаке $A < 0$) и энергетический баланс.

## 4. Неоднородный слой (разделы 1.1.2, 1.1.4)

Книга указывает, что ступенчатая аппроксимация непрерывного профиля даёт лишь первый порядок точности, и рекомендует интегрировать уравнения поля (1.1.9), (1.1.14) или уравнение Риккати для локальной функции отражения (1.1.19), (1.1.20):

$$\frac{dr}{dz} = \frac{ik}{2q_a}\left[q_a^2(1-r)^2 - (\varepsilon(z) - \alpha^2)(1+r)^2\right] \ (s),\qquad \frac{dr}{dz} = \frac{ik}{2q_a}\left[q_a^2\Big(1 - \frac{\alpha^2}{\varepsilon(z)}\Big)(1-r)^2 - \varepsilon(z)(1+r)^2\right] \ (p),$$

$r(0) = (q_a - q_s)/(q_a + q_s)$. Уравнения выведены заново из (1.1.9), (1.1.14) и (1.1.18) (в извлечённом тексте формулы читаются плохо) и реализованы дважды: независимо в тесте и в ядре (`rhoGraded`, RK4, шаг 0.5 нм; EMA-слой сверху добавляется шагом Эйри после пересчёта $r$ к среде ЭС через $w = v/u$).

Проверки: для однородной плёнки решение Риккати совпадает с Эйри до $10^{-9}$; сходимость по шагу четвёртого порядка (ошибка $1.7\cdot10^{-2}$° при 2 нм, $1.1\cdot10^{-3}$° при 1 нм, $6.8\cdot10^{-5}$° при 0.5 нм); ветвь с EMA-слоем при $\delta \to 0$ совпадает с Эйри.

Ошибка лестницы из $M$ подслоёв (центры подслоёв) относительно непрерывного профиля, TiO₂ 1000 нм на BK7, 65°, в единицах шума $\sigma_\Psi \approx 0.02°$, $\sigma_\Delta = 2.2\sigma_\Psi$ (RMS по 400–800 нм):

| $\delta$ | $M = 10$ | $M = 20$ | $M = 40$ | $M = 80$ | $M = 160$ |
|---|---|---|---|---|---|
| 1 % | Ψ 3.0σ, Δ 4.8σ | 0.12σ, 0.45σ | 0.03σ, 0.10σ | 0.01σ, 0.03σ | 0.00σ, 0.01σ |
| 5 % | 14σ, 26σ | 0.56σ, 2.4σ | 0.13σ, 0.55σ | 0.03σ, 0.13σ | 0.01σ, 0.03σ |
| 12 % | 30σ, 81σ | 1.2σ, 6.1σ | 0.27σ, 1.4σ | 0.07σ, 0.35σ | 0.02σ, 0.09σ |

Ошибка убывает как $1/M^2$: лестница по центрам подслоёв даёт второй порядок, а не первый (замечание книги относится к наивной ступенчатой аппроксимации). Принятые решения: истина в симуляторе считается непрерывным профилем (Риккати, по умолчанию); окончательный фит использует 40 подслоёв, переходит на 80 при $|\delta| > 4$ % и на 160 при $|\delta| > 12$ % (ошибка модели по Δ $\le 0.35\sigma$ во всём допустимом диапазоне $\pm20$ %; с 80 подслоями при 20 % было бы 0.66σ — см. разд. 7); генерация обучающих остатков остаётся на 40 подслоях (ошибка $\le 0.55\sigma$ при 5 % не влияет на классификацию).

## 4а. Производные спектральных коэффициентов (раздел 1.4.1)

Реализованы формулы книги для аналитического якобиана: характеристические матрицы (1.4.2), $D_j = \partial M_j/\partial d_j$ (1.4.9), $\partial M_j/\partial \tilde n_j$ (через $\varphi_j = k d_j\sqrt{\tilde n_j^2 - \alpha^2}$, $q_j$ для $s$ и $p$; в $p$-случае множитель $(1 - \tan^2\gamma_j)/\cos\gamma_j$), матрица $\Psi_r$ (1.4.10) и след $\partial r/\partial x_j = \mathrm{Tr}(\Psi_r^{j-1}M^{j+1}X_j)$ (1.4.12, 1.4.16) с префиксными и суффиксными произведениями (1.4.13–1.4.15); переход к глобальным параметрам модели — цепным правилом (толщина → толщины подслоёв; $\delta$, $A$, $A_{uv}$, $E_g$ → показатели подслоёв и слоя Бруггемана). Сверка с центральными разностями для стека из 42 слоёв (TiO₂ с градиентом и EMA-слоем на BK7 при 65°; Si₃N₄ на c-Si при 70°) по шести параметрам: максимальное относительное расхождение $1$–$2\cdot10^{-8}$ — уровень ошибки усечения самих разностей. Знак $r_p$ и производных приведён к эллипсометрической конвенции. Стоимость якобиана по 6 параметрам — около 4 вычислений модели.

## 4б. Хвост поглощения (дефект «поглощение», v1.1.0)

Хвост — второй осциллятор Тауца–Лоренца с теми же $E_0$, $C$, порогом $E_t$ = 1.2 эВ и силой $A_k$; $\varepsilon = \varepsilon^{TL} + \varepsilon^{uv} + \varepsilon^{tail}$. Проверки (`npm run verify:book`, разделы 5–6 скрипта):

* **Причинность.** $\varepsilon_1^{tail}$ — аналитическое КК-выражение Джеллисона–Модина для параметров хвоста; независимо вычислен интеграл Крамерса–Кронига $\varepsilon_1(E) - 1 = \frac{2}{\pi}\,\mathrm{P}\!\int_0^\infty \frac{E'\varepsilon_2(E')}{E'^2 - E^2}\,dE'$ (особенность выделена вычитанием, хвост интеграла до 400 эВ, 4·10⁵ узлов): расхождение с аналитикой $\le 9\cdot10^{-5}$ в 1.5–3.6 эВ для хвоста ($E_0$ = 4.0, $C$ = 1.77, $E_t$ = 1.2) и $5\cdot10^{-6}$ для основного осциллятора TiO₂ — на уровне ошибки численного интегрирования.
* **Форма.** $k$ хвоста монотонно растёт к синему краю: при $k_{400} = 10^{-3}$ (TiO₂) $k$ = 1.0·10⁻³, 3.7·10⁻⁴, 1.6·10⁻⁴, 7.1·10⁻⁵, 2.8·10⁻⁵ при 400, 500, 600, 700, 800 нм (отношение 400/800 ≈ 36); `tailAk` обращает `tailK400` до 10⁻⁹. Вклад хвоста в $n$ по КК — 1.2–1.7·10⁻³.
* **Производная.** Аналитический якобиан расширен параметром $A_k$ ($\partial\varepsilon/\partial A_k$ — хвост единичной силы, далее цепное правило через подслои и слой Бруггемана как для $A$): сверка с центральными разностями по 7 параметрам для стека из 42 слоёв (TiO₂ с градиентом, EMA-слоем и хвостом на BK7, 65°; Si₃N₄ на c-Si, 70°) — относительное расхождение $\le 7\cdot10^{-7}$, уровень округления самих разностей. «Данные» в этой проверке — модель со сдвигом 0.1° по Ψ и 1° по Δ (раньше нули), чтобы невязка была мала и не попадала на разрыв wrap при Δ = 180°.
* **Сигнатура.** В полуволновых точках однородная прозрачная плёнка «отсутствует» (Ψ = Ψ подложки при любых $n$, $d$), поэтому Ψ-остаток в HW-якорях не зависит от компенсации дисперсией: градиент даёт сдвиг, примерно постоянный по диапазону, хвост поглощения — сдвиг, растущий к синему краю $\propto k(\lambda)d/\lambda$; в QW-якорях контраст гасится с другой стороны полосы. Численно (TiO₂/BK7 1017 нм, HfO₂/Si 933 нм, Si₃N₄/Si 612 нм, $\sigma_\Psi$ = 0.015–0.035°): при $k_{400} = 10^{-4}$ RMS Ψ-остатка опорного фита в синей трети диапазона 0.8–4σ против 0.2–1.3σ в красной, $\chi^2/\nu$ 0.2–3.9; при $3\cdot10^{-4}$ — 2–7σ против 0.5–2.8σ, т.е. порог обнаружения ≈ 1–3·10⁻⁴ (на кремнии ниже, чем на стекле).
* **Ложные минимумы.** Опорный фит без хвоста компенсирует затухание полос ростом $A$ и $E_g$ (Si₃N₄/Si при $k_{400} = 3\cdot10^{-3}$: $A$ 276 вместо 157, $E_g$ 5.07 вместо 4.60, $d$ на 4.5 нм меньше); окончательный фит из такого старта сходился к ложному минимуму ($\chi^2/\nu$ 30–120, $k_{400}$ в 2–4 раза меньше истинного) для HfO₂/Si при $10^{-3}$ и $10^{-2}$ и Si₃N₄/Si при $3\cdot10^{-3}$ и $10^{-2}$; раунд разведки по силе хвоста × дисперсии (опорная / справочная) во всех случаях приводит к истине ($\chi^2/\nu$ 0.04–1.2 — остаток от неучтённой полосы 1 нм; без полосы — восстановление точное).

## 4в. Задняя сторона подложки (v1.2.0)

Книга рассматривает подложку как полубесконечную среду; для плоскопараллельной прозрачной подложки в приложении добавлено некогерентное сложение пучков, отражённых её задней гранью (раздел 3.4 README). Нужны коэффициенты стопки с обеих сторон, и они получены из матричного метода книги (1.2.9–1.2.14): для стопки в обратном порядке характеристическая матрица $M' = J M^{\mathsf T} J = [[m_{22}, m_{12}], [m_{21}, m_{11}]]$ (так как каждая $M_j$ имеет вид $[[a, b], [c, a]]$ и $J M_j^{\mathsf T} J = M_j$), откуда при общем знаменателе $r' = (-q_a m_{11} + q_a q_s m_{12} + q_s m_{22} - m_{21})/den$, $t' = 2q_s/den$. Проверки (`npm run verify:book`, раздел 7 скрипта):

* $f \to 0$: $\mathcal N, \mathcal C, \mathcal S$ матричного метода с некогерентной суммой совпадают с рекурсией Эйри ядра для стека из 42 слоёв до $5\cdot10^{-15}$.
* $r'$, $t'$ из тождества против прямого расчёта обращённой стопки (свет из подложки, слои в обратном порядке, «подложка» — воздух): $6\cdot10^{-16}$.
* Голая пластина BK7, 65°: произведение тангенциальных амплитуд $|t t'|^2$ равно произведению энергетических пропусканий $T\,T_b$ (косинусные множители тангенциальных амплитуд p-волны сокращаются в произведении «туда–обратно»), и полное отражение совпадает с классической некогерентной суммой $R + T T_b R_b/(1 - R_b^2)$ для s и p до $10^{-16}$; Ψ при 550 нм растёт с 12.914° до 14.213° при $f = 1$, Δ остаётся 0° (все амплитуды вещественны).
* Величина эффекта: TiO₂ 1017 нм на BK7, 65°, $f = 1$ — $|\Delta\Psi|$ до 2.6°, $|\Delta\Delta|$ до 26°; фит такого спектра моделью без задней стороны даёт $\chi^2/\nu \approx 3\cdot10^4$, толщину с ошибкой 62 нм и градиент −7.4 % вместо −0.8 %; с задней стороной — $\chi^2/\nu = 1.4$, $d$ с ошибкой 0.75 нм (та же, что без задней стороны, от отклонения дисперсии). Для Si₃N₄ на c-Si 0.5 мм вклад $2.8\cdot10^{-14}$° — поглощающая подложка гасит его сама через $w = |e^{-2ikd_sN_s\cos\gamma_s}|^2$.
* Якобиан в этом режиме — центральные разности по невязке (аналитические производные книги выведены для $r$; для $t$, $r'$, $t'$ они получаются теми же следами с другими матрицами $\Psi$, но пока не реализованы): при $f \to 0$ он совпадает с аналитическим до $2\cdot10^{-5}$ (уровень округления разностей).

## 5. Энергия и предельные случаи (раздел 1.1.5)

* Непоглощающая плёнка на стекле, 60°: $R + T - 1 = 2\cdot10^{-16}$ для обеих поляризаций.
* Поглощающая плёнка (TiO₂ при 340 нм, $N = 2.853 - 0.108i$) на BK7, 60°: $A_s = 0.403$, $A_p = 0.701$ — положительны.
* Угол Брюстера BK7 при 550 нм (56.63°): $|r_p| < 10^{-6}$; голый диэлектрик: $\Delta = 180°$ при 45°, $0°$ при 70°; нормальное падение: $r_p = -r_s$.

## 6. Что в книге не рассматривается и как проверено отдельно

* **Дисперсия Тауца–Лоренца + УФ-полюс**: аналитическое выражение $\varepsilon_1$ (Jellison–Modine) сверено с численным интегралом Крамерса–Кронига (совпадение до $10^{-6}$ в прототипе на Python; ядро на JavaScript совпадает с прототипом до $10^{-13}$ по Ψ, Δ). Условие существования $4E_0^2 > C^2$ и $E_g < E_0$ контролируется в интерфейсе.
* **Эффективная среда Бруггемана**: корень квадратного уравнения удовлетворяет исходному уравнению ЭС с невязкой $10^{-17}$, $1 < \varepsilon_{\text{ema}} < \varepsilon_{\text{плёнки}}$, мнимая часть показателя отрицательна.
* **Нормированные элементы матрицы Мюллера** $\mathcal N, \mathcal C, \mathcal S$ и свёртка со спектральной полосой: усредняются интенсивностные величины, а не углы; $\Psi = \tfrac12\arccos\mathcal N$, $\Delta = \operatorname{atan2}(\mathcal S, \mathcal C)$ восстанавливают Ψ, Δ точно при нулевой полосе.
* **Производные по параметрам** (раздел 1.4.1 книги): реализованы аналитически, см. 4а; с v1.1.0 — и по силе хвоста поглощения $A_k$ (4б).

## 7. Проверка v1.2.0 двумя независимыми рецензентами и исправления v1.2.1

Помимо сверки с книгой, ядро v1.2.0 проверено двумя независимыми способами: (а) когерентный расчёт пластины воздух | слои | подложка | воздух в другой конвенции (N = n + ik, e^{−iωt}) с усреднением по фазе двойного прохода подложки — совпадение с `ncsBackside` по N, C, S до 10⁻¹⁴ при f = 1 и 0.96, с градиентом, слоем ЭС и поглощающей плёнкой, выше и ниже Брюстера (второй рецензент: усреднение по 8192 фазам, < 4·10⁻¹¹); (б) численный интеграл Крамерса–Кронига (scipy, вес Коши) для ε₁ Тауца–Лоренца всех 11 материалов и хвоста — совпадение 10⁻⁷–10⁻¹⁰. Оптика ядра ошибок не содержит. Найденные ошибки лежали в синтезе измерения, справочных данных и оформлении результата; все исправлены в v1.2.1 и покрыты проверками `npm run verify:book` (разделы 8–10 скрипта):

**Полоса в модели фита.** Гауссова полоса с σ = FWHM/2.3548 даёт ⟨M⟩ = Σ σ^{2k} M^{(2k)}/(2^k k!) для ненормированных элементов Мюллера M ∈ {I_p, I_s, Re Z, Im Z}; берётся второй порядок M + (σ²/2)M″ с центральной разностью по λ, h = 1 нм. Для синусоиды периода P отброшенный член равен [(σ²/2)(2π/P)²]²/2 — при σ = 0.6 нм и P = 20 нм это 1.6·10⁻⁴ от сигнала (0.016° по Δ), при P ≥ 28 нм < 4·10⁻⁵; ошибка разности (h²/12)(2π/P)² < 0.5 % от поправки. Ψ, Δ и производные — из ⟨M⟩: Ψ = ½ arccos N, Δ = atan2(S, C), dΨ = −dN/(2 sin 2Ψ), dΔ = (C dS − S dC)/(C² + S²).

**Деполяризация при задней стороне.** При f = 0.96 (образец 09) 1 − √(N² + C² + S²) достигает 6.7 %; «эффективные» Ψ, Δ зависят от определения: Ψ = ½ arccos N (принято в приложении) и Ψ с нормировкой на степень поляризации расходятся до 5°, Δ = atan2(S, C) и acos(C/sin 2Ψ) — до 176°. Внутри приложения всё согласовано; для реального прибора определение нужно сверять (см. README, разд. 10).
